# Collaboration

Use Claude Fable 5.1 where available for substantial bounded implementation and
independent review. Disclose unavailable models. Main agent owns shared interfaces,
integration, acceptance evidence, commits and pushes. Never assume a subagent's
summary proves a change works. Use separate worktrees and explicit file ownership.

Keep root manifests, binding registration, public wire contracts, README and status
under integration ownership. Implementers own named modules and module tests/docs.
No force pushes or gate bypasses. Measurements and generated recordings stay local.
